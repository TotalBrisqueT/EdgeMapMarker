# Changelog

## 0.1.0

- First release.
- Edge marker with icon, arrow and distance for targets off the minimap.
- Track home, any map pin, and other players (Left Alt + click on the large map), saved per character and world.
- Ping-style HUD markers for tracked targets.
- Badge or ring on tracked pins.
- Per-player colours picked from the character name.
- SharedMap compatibility.
