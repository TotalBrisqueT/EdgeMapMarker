# Changelog

## 1.0.1

- New plugin ID, `SunPheonyx.EdgeMapMarker`. The config file gets a new name, so settings return to their defaults once. Tracked pins, players and home are not affected.

## 1.0.0

- First public release. Same features as 0.1.2, tested in a three-player session.

## 0.1.2

- Per-target views: Left Alt + right-click a tracked target on the large map to cycle between minimap + HUD, minimap only and HUD only. New targets show on both.
- Left Alt + right-click no longer deletes the pin under the cursor.

## 0.1.1

- Keys to show/hide all HUD markers (Left Alt + H) and the icons above them (Left Alt + I).
- Tracked-pin highlight is now green by default (amber blended in with SharedMap's public markers).

## 0.1.0

- First release.
- Edge marker with icon, arrow and distance for targets off the minimap.
- Track home, any map pin, and other players (Left Alt + click on the large map), saved per character and world.
- Ping-style HUD markers for tracked targets.
- Badge or ring on tracked pins.
- Per-player colours picked from the character name.
- SharedMap compatibility.
